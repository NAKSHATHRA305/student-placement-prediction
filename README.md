# Student Placement Prediction 🎓

ML model that predicts whether a student will get placed based 
on academic and experiential features.

## Tech Stack
`Python` `scikit-learn` `pandas` `Random Forest`

## Features Used
| Feature | Description |
|---|---|
| CGPA | Academic performance |
| Internships | Number completed |
| Projects | Academic/personal projects |
| Backlogs | Standing arrears |
| Age | Student age |

## Models Compared
| Model | Accuracy |
|---|---|
| Random Forest | ~85–92% ✅ best |
| Logistic Regression | compared |
| Decision Tree | compared |

## Dataset
Kaggle — Student Placement Prediction Dataset

## Run
pip install -r requirements.txt
python model.py
